# ☕ Coffee Sales Excel Dashboard

## 📊 Project Overview
This project is an Excel-based data analysis and interactive dashboard built using a Coffee Sales dataset.  
The goal is to explore sales performance, identify trends, and extract meaningful business insights using Excel.

---

## 🧹 Data Cleaning
The dataset was prepared and cleaned in Excel by performing the following steps:
- Removed duplicate records  
- Handled missing and inconsistent values  
- Standardized date and numeric formats  
- Structured raw data for analysis  

---

## 📈 Data Analysis
The following analytical steps were performed:

- Analyzed total sales over time to identify trends  
- Compared sales performance across different countries  
- Ranked customers based on total purchase value  
- Used Pivot Tables to summarize and aggregate data  
- Extracted key metrics (KPIs) from the dataset  

---

## 📊 Dashboard Features
The Excel dashboard includes the following visualizations:

- 📊 Bar Chart: Sales by Country  
- 🏆 Bar Chart: Top 5 Customers by Revenue  
- 📈 Line Chart: Total Sales Over Time  

The dashboard is interactive and includes filters for exploring different segments of the data.

---

## 🛠 Tools Used
- Microsoft Excel  
  - Pivot Tables  
  - Charts & Graphs  
  - Data Cleaning Functions  
  - Data Visualization Tools  

---

## 📌 Key Insights
- Sales performance varies significantly across countries  
- A small group of customers contributes a large portion of total revenue  
- Sales trends show clear fluctuations over time  
- Customer segmentation helps identify high-value clients
